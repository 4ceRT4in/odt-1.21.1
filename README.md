# OneDayTitan für Fabric 1.21.1

Ein 1.21.1 OneDayTitan serverside addon für TitanReborn

## Befehle

`<Spieler>` steht für den Namen eines Spielers. „Level“ bezeichnet die Minecraft-Berechtigungsstufe.

| Befehl | Level | Erklärung |
| --- | ---: | --- |
| `/border` | Alle | Zeigt die aktuelle Größe der Weltgrenze. |
| `/spawn` | Alle | Zeigt die gespeicherten Spawn-Koordinaten an. |
| `/tteam invite <Spieler>` | Alle | Lädt einen Spieler in der Duo-Lobby für 30 Sekunden ins Team ein. |
| `/tteam accept <Spieler>` | Alle | Nimmt die Team-Einladung dieses Spielers an. |
| `/tteam leave` | Alle | Verlässt das Team, solange das Spiel in der Lobby ist. |
| `/abortprotectiontime` | 2 | Beendet die laufende Schutzzeit sofort. |
| `/invsee <Spieler>` | 2 | Öffnet das Inventar eines Online-Spielers inklusive Rüstung, Nebenhand und SaveInv. |
| `/reloadconfig` | 2 | Lädt gespeicherte Team- und Spielerdaten neu. |
| `/revive <Spieler>` | 2 | Belebt einen ausgeschiedenen Spieler wieder. |
| `/setspawn` | 2 | Speichert die eigene Position als Spawn und zentriert dort die Weltgrenze. |
| `/setstartstuff` | 2 | Speichert das eigene Inventar als Startausrüstung. |
| `/start` | 2 | Startet den 30-Sekunden-Countdown zum Spielbeginn. |
| `/startfinale` | 2 | Startet den 30-Sekunden-Countdown zum Finale. Danach gelten 30 Sekunden Schutzzeit. |
| `/teamsize solos` | 2 | Stellt vor Spielbeginn auf Einzelspieler um. |
| `/teamsize duos` | 2 | Stellt vor Spielbeginn auf Zweierteams um. |
| `/reset` | 4 | Zeigt die erforderliche Bestätigung für den Reset an. |
| `/reset confirm` | 4 | Löscht Spielkonfiguration und Weltordner und fährt den Server herunter. |
